# 👋 Hey, I'm Andrew!

## 🧭 About Me

I'm a developer who grew from **Web2 foundations** — solid architecture, UI/UX precision, data-driven backends —  
and now expanding into **Web3 ecosystems**, combining decentralization, smart contracts, and social good.

I believe in creating products that are **useful, beautiful, and meaningful** — whether it’s a modern SaaS dashboard or a multi-chain DAO.

## 💼 What I Build

### 🖥️ Web2 Foundations
- **Frontend:** Next.js, React, Tailwind CSS, Framer Motion, GSAP, Lottie  
- **Backend:** NestJS, TypeORM, Supabase, PostgreSQL, REST & GraphQL APIs  

### 🕸️ Web3 Expansion
- **Smart Contracts:** Solidity (ERC-721, ERC-1155, ERC-4337, ERC-4906, DAO logic, etc)  
- **Chains:** Base, Lisk, Optimism, Arbitrum, FlowEVM  
- **Wallets & UX:** Thirdweb, RainbowKit, Coinbase Smart Wallet  
- **Infra:** Hardhat, Ponder, Chainlink, LayerZero, Supabase onchain sync  
- **Patterns:** Upgradeable contracts, minimal proxies, account abstraction, metadata updates
